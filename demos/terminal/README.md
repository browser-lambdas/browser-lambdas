# Terminal

Three terminal styles: Zebra, [Catppuccin Mocha](https://github.com/catppuccin/catppuccin#-palette), and Glass. No external assets or fonts are required; Glass keeps a solid fallback when blur is unavailable.

From this directory, run `baah push <connection>` and approve the import in the extension. Preview and select a theme in Settings → Terminal → Theme, or in the style's workspace settings.

Importing leaves your current theme selected.
