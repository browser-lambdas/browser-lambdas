# Bundled fonts

Lato and Fira Mono are bundled so extension UI and code render without installed fonts or runtime network requests. Downloaded from the Google Fonts repository on 2026-10-06:

- https://github.com/google/fonts/tree/main/ofl/lato
- https://github.com/google/fonts/tree/main/ofl/firamono

Both families use the SIL Open Font License; see `lato-OFL.txt` and `firamono-OFL.txt`.

Lato includes Thin (100), Light (300), Regular (400), Bold (700), Black (900), and Regular Italic. The gutter's requested weight 200 resolves to Thin; Lato has no separate static 200 font in this distribution. Fira Mono includes Regular (400), Medium (500), and Bold (700).
